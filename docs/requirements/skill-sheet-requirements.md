# スキルシート要件

今回確認した自社スキルシートExcelの構造をもとに、Web化にあたっての要件を整理する。

- 作成日: 2026-08-03
- 更新日: 2026-08-04（下書き自動保存仕様を反映）
- ステータス: ドラフト

---

## 1. 基本方針

Excelの見た目をそのままWeb上に再現しない。

情報を以下の単位に分けて管理する。

1. 基本情報
2. スキル
3. 資格
4. 職歴
5. 自己PR

Excelは初期インポート用の**入力アダプター**とし、ブラウザ移行後はDBを正本とする。

---

## 2. 基本情報

管理候補項目は以下とする。

| 項目 | 備考 |
|------|------|
| 氏名 | |
| フリガナ | |
| 性別 | |
| 生年月日 | |
| 年齢 | DBへ固定値として保存せず、生年月日から算出する |
| 居住地 | 必要な粒度に分割（下記参照） |
| 最寄駅 | |
| 最終学歴 | |
| 就業状況 | |
| 勤怠提出元 | 参画中メンバーについて、勤怠が上位会社から提出されるか、参画中メンバー本人から提出されるかを表示する |
| 希望単価 | |
| 希望勤務地 | |
| リモート希望 | |
| 転職意向 | |
| 最終更新日 | |

### 補足

- **年齢はDBへ固定値として保存しない。** 生年月日から算出する。
- 住所全文が案件マッチングに不要な場合は、居住都道府県、市区町村、最寄駅など必要な粒度に分ける。
- 勤怠提出元は参画中メンバーに対して表示する。選択肢は「上位会社」「参画中メンバー」を基本とする。

## 3. スキル

以下の情報を管理する。

- スキル名
- カテゴリ
- 経験期間
- 最終利用時期
- 表示順
- 備考

### 補足

- MVPでは、経験期間や最終利用時期の**自動集計は必須としない**。
- 職歴上の使用技術から自動集計する方式は将来対応とする。

---

## 4. 資格

以下を管理する。

- 資格名
- 取得年月
- 備考
- 表示順

---

## 5. 職歴

職歴は繰り返し追加可能な構造とする。

職歴1件あたり、以下を管理する。

- 表示順
- 開始年月
- 終了年月
- 現在参画中フラグ
- プロジェクト名
- 業務内容
- 役割
- チーム人数
- 使用環境
- 使用技術
- 担当工程
- 備考

### 担当工程の候補

- 要件定義
- 基本設計
- 詳細設計
- 設計構築
- 製造
- テスト
- 運用保守
- サポート

### 操作要件

職歴は、以下ができる構成を想定する。

- 追加
- 編集
- 削除
- 並び替え
- 複製

## 7. 下書き保存

スキルシート編集中は、入力途中の内容を下書きとして保持する。

### 自動保存

- スキルシート編集画面を開いている間、1分おきに下書きへの自動保存を実行する
- 下書きには、基本情報、スキル、資格、職歴、自己PRなど、編集画面で入力中の内容を保存する
- 下書き保存は正式保存ではなく、編集途中の復元用データとして扱う

### 正式保存時の扱い

- 「保存する」ボタンを押下した場合、現在の入力データを正式データとして保存する
- 正式保存が完了したら、該当スキルシートの下書きは破棄する
- 正式保存後は、保存前の正式データを現在の入力データで上書きする

### キャンセル時の扱い

- 「キャンセル」を押下した場合、該当スキルシートの下書きは破棄する
- キャンセル時は、入力途中の内容を正式データへ反映しない

### 下書き復元

- 下書きが残っている状態でブラウザを閉じる、画面遷移するなどして編集を中断した場合、次回スキルシート編集画面を開いたときに下書き復元確認のポップアップを表示する
- ポップアップで「はい」を押下した場合、下書きの内容を入力欄に反映する
- ポップアップで「いいえ」を押下した場合、下書きを破棄し、正式保存済みデータを入力欄に表示する

## 8. PDF

外部提出、メール添付、印刷用としてPDFを利用する。

- MVPでは、専用PDF生成基盤を必須とせず、**印刷用HTMLとブラウザのPDF保存機能で対応してもよい**
- 個人情報の公開範囲やマスキング機能は将来対応とする

---

## 9. Excelインポート

対象は今回確認したExcelフォーマット**1種類に限定する**。

### 処理の流れ

1. Excelアップロード
2. Excel内容解析
3. 解析結果をブラウザ上に表示
4. ユーザーが内容を確認、修正
5. DBへ登録
6. 以降はブラウザ上で編集

### 前提

- Excelファイル自体を正本として運用しない
- Excelへの再出力は行わない
