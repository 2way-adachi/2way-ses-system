# MVP要件定義

SES補助システム MVP（Minimum Viable Product）の要件をまとめる。

- 作成日: 2026-08-03
- 更新日: 2026-08-17（SESメニュー再整理、メンバー詳細・マッチング・提案管理導線を反映。同日、Excelインポート中止と実装状況注記を追記）
- ステータス: ドラフト

> **実装状況**: 実装が本要件の再整理より先に進んでおり、乖離がある
> （スキルシート・マッチング・提案は実装済みだが構成が異なる。メール取り込みは画面モックのみ）。
> 詳細は [実装現状の記録](../development/implementation-status.md) を参照。

---

## 0. 実現方式

本システムは**独立したWebシステムとして構築せず、既存の管理画面Lavender（2way Manage system）の1機能として追加する**。

Lavenderのサイドバーに、FUKURO2.0とは別の大項目「SES」を新設し、その配下に以下を追加する。

- 案件メール一覧
- 要員メール一覧
- メンバー一覧
- マッチング一覧
- 提案管理一覧

詳細は [Lavender組み込み要件](lavender-integration.md) を参照。

---

## 1. システム概要

### 現状

現在、SES事業の情報は以下のように管理されている。

| 情報 | 管理方法 |
|------|----------|
| スキルシート | Excelファイル |
| 案件情報 | メール |

### 課題

- 情報がファイルやメールに分散している
- 最新版が分かりにくい
- 検索や一覧化が難しい
- 案件と人材情報を横断的に利用できない
- スキルシートの更新や共有に手間がかかる

### MVPで目指す状態

スキルシートと案件情報をDBに格納し、ブラウザ上から管理可能にする。

MVPの中心は次の軸とする。

1. 案件メールからの案件情報格納自動化
2. 要員メールからの要員情報格納自動化
3. メンバー情報とスキルシートの管理
4. 案件と要員のマッチング管理
5. 承認済みマッチングを起点とした提案管理

マッチングと提案管理は、案件・要員・メンバー情報を横断して営業状況を把握するための機能として扱う。

---

## 2. システム全体方針

本システムの前提となる方針を以下に定める。

- **Lavenderの1機能として追加する**（独立サービスとして作らない）
- Lavenderのサイドバーに、FUKURO2.0とは別の大項目「SES」を新設する
- 認証・共通レイアウトはLavender既存のものを利用する
- **DB上の情報を正本とする**
- スキルシートは移行後、ブラウザ上で新規作成、参照、編集する
- SESメニューは「案件メール一覧」「要員メール一覧」「メンバー一覧」「マッチング一覧」「提案管理一覧」で構成する
- スキルシートは独立メニューではなく、メンバー詳細内の「スキルシート」タブで確認、編集する
- **Excelインポートは中止した**（2026-08-16決定。理由: 利用頻度が少なく開発工数を回収できない恐れ）。
  既存Excelの内容はブラウザ上での新規作成で移行する
- **Excelへの再出力は行わない**
- 外部提出、メール添付、印刷などが必要な場合はPDFを利用する（印刷用HTML＋ブラウザ印刷で実装済み）
- 高度なAI解析、面談結果や提案結果を用いた機械学習、詳細な承認ワークフロー、詳細な権限管理はMVP対象外とする

## 3. MVP対象機能

### 3.1 案件メール管理

> 実装状況: 画面モックのみ（`/project`）。メール取り込みバッチ・API未実装。

- 案件メール一覧表示
- 案件メールから取得した案件の一覧表示
- 案件詳細表示
- 案件情報の編集
- メールサービスとの接続
- 対象メールの取得
- メール件名、本文、送信元、受信日時の保存
- 案件情報の抽出
- 案件DBへの登録
- 重複登録防止
- メール取り込み履歴の確認

### 3.2 要員メール管理

> 実装状況: 画面モックのみ（`/staff`）。メール取り込みバッチ・API未実装。

- 要員メール一覧表示
- 要員メールから取得した要員の一覧表示
- 要員詳細表示
- 要員情報の編集
- メール件名、本文、送信元、受信日時の保存
- 要員情報の抽出
- 要員DBまたはメンバー候補DBへの登録
- 重複登録防止
- メール取り込み履歴の確認

### 3.3 メンバー管理

> 実装状況: 「要員（personnel）」として一覧・詳細（4タブ）を実装済み・実API接続。
> パス・タブ名・タブ集約の構成は本要件と異なる。要員の登録・編集画面は未実装。

- メンバー一覧表示
- メンバー詳細表示
- メンバー詳細内のタブ表示
  - info
  - スキルシート
  - 提案
  - マッチング
- メンバーの基本情報、スキルシート、提案状況、マッチング状況を横断して確認できる
- メンバー一覧を押下するとメンバー詳細へ遷移する

### 3.4 スキルシート管理

- スキルシート一覧表示
- スキルシート詳細表示
- スキルシート新規作成
- スキルシート編集
- メンバー詳細の「スキルシート」タブでの表示、編集
- 職歴の追加、編集、削除
- スキルの追加、編集、削除
- 資格の追加、編集、削除
- 自己PRの編集
- ~~既存Excelからの初期取り込み~~ → **中止**（2026-08-16決定）
- PDF表示（印刷用HTML＋ブラウザ印刷で実装済み）

詳細は [skill-sheet-requirements.md](skill-sheet-requirements.md) を参照。

> 実装状況: スキルシートの一覧・詳細・新規作成・編集・下書き・PDFは**独立メニューとして実装済み**
> （実DB結合確認済み）。メンバー詳細タブへの集約は未追従。

### 3.5 マッチング管理

> 実装状況: マッチング自体は**スキルマスタ（skill_id）方式**で実装済み（本要件の文字列比較とは方式が異なる）。
> ただし単独の「マッチング一覧」画面と承認/見送り操作は未実装（案件詳細・要員詳細内での表示のみ）。

- 要員と案件をマッチングし、結果を一覧表示する
- マッチング一覧には、案件名、必須技術、案件開始時期、要員名、点数などを表示する
- スキル評価は、必須スキル一致率80%・尚可スキル一致率20%で算出する
- 条件適合は項目別に判定し、判定理由を保持・表示できるようにする
  - 単価、稼働形態、稼働開始時期、年齢、商流: OK / WARNING / NG
  - 外国籍可否、個人事業主: OK / NG
  - 場所は初期版では自動判定せず、案件側の場所と要員側の希望エリアを表示して営業担当が判断する
- 条件適合にNGが1件でも含まれる場合はマッチング対象外とする
- NGがない場合は、WARNING件数に応じた条件係数をスキル評価に掛けて総合点を算出する
  - WARNING 0件: 1.00
  - WARNING 1件: 0.90
  - WARNING 2件: 0.80
  - WARNING 3件以上: 0.70
- マッチングを押下すると、該当メンバー詳細の「マッチング」タブを表示する
- メンバー詳細の「マッチング」タブで、そのメンバーにマッチングしている案件を確認できる
- マッチング結果を承認または見送りできる

### 3.6 提案管理

> 実装状況: 提案一覧・作成・更新（6ステータス）は実装済み・実API接続。
> ただし「承認済みマッチング起点」ではなくマッチング結果から直接作成する構成で、次回アクション日も未実装。

- マッチングで承認した提案を一覧表示する
- 提案管理一覧には、案件名、必須技術、案件開始時期、要員名、次回アクション日、進捗ステータスなどを表示する
- 提案を押下すると、該当メンバー詳細の「提案」タブを表示する
- メンバー詳細の「提案」タブで、そのメンバーの提案状況を確認できる
- 提案ステータス、次回アクション日、メモを更新できる

---

## 4. MVP対象外

以下はMVPのスコープ外とする。

- 高精度なAIマッチング
- 面談結果や提案結果を用いた機械学習
- **Excelインポート全般**（2026-08-16中止。フォーマット対応の論点ごと消滅）
- Excelへの再出力
- 請求管理
- 契約管理
- 勤怠管理
- 営業管理全般
- 承認ワークフロー
- 詳細な変更履歴比較
- 複雑な権限管理（ただし、スキルシート初期表示に必要な管理者 / 非管理者の判定はMVP対象に含める）
- メールへのPDF自動添付
- リアルタイムメール受信

## 6. 完成条件

MVPの完成は以下をすべて満たした状態とする。

- [x] スキルシートをブラウザ上で作成、参照、編集できる（実装済み・結合確認済み。未コミット）
- ~~既存ExcelをDBへ初期取り込みできる~~ → **中止により対象外**（2026-08-16）
- [ ] メールから案件情報を取得し、DBへ保存できる
- [ ] メールから要員情報を取得し、DBへ保存できる
- [ ] 登録した案件を一覧、詳細画面で確認できる
- [ ] 登録した要員を一覧、詳細画面で確認できる
- [ ] メンバー詳細でinfo、スキルシート、提案、マッチングを確認できる
- [ ] マッチング一覧からメンバー詳細のマッチングタブへ遷移できる
- [ ] 提案管理一覧からメンバー詳細の提案タブへ遷移できる
- [ ] 案件情報の抽出誤りを画面から修正できる
- [ ] 同じメールが重複登録されない

| 勤怠提出元の保持単位 | 職歴ごと → **スキルシート単位に変更**。任意入力 | 08-12 |
