## 3. 未追従項目の詳細

### #1 勤怠提出元の追加

- **起点コミット**: `66cb1dd` docs: add attendance submission source requirement
- **要件の出典**:
  - [スキルシート要件 2. 基本情報](../requirements/skill-sheet-requirements.md)
  - [画面設計 3・4・5章](../design/screen-design.md)
  - [データモデル 2.1 skill_sheets](../design/data-model.md)

#### 要件の内容

- 基本情報に「勤怠提出元」を追加する
- 参画中メンバーについて、勤怠が**上位会社**から提出されるか、**参画中メンバー**本人から提出されるかを表示する
- 選択肢は「上位会社」「参画中メンバー」を基本とする
- DBカラムは `attendance_submission_source`（候補値 `upper_company` / `current_member`）

#### モックに必要な修正

| 画面 | 修正内容 |
|------|---------|
| スキルシート一覧 | 表示列に「勤怠提出元」を追加 |
| スキルシート詳細 | 基本情報セクションに「勤怠提出元」の行を追加（参画中メンバーのみ表示） |
| スキルシート編集 | 基本情報タブに選択欄（上位会社／参画中メンバー）を追加 |
| Excelインポート | 解析結果の基本情報に項目を追加。件数表示「基本情報 13項目」の見直し |
| ダミーデータ | 4名分に値を設定。就業状況が「待機中」の人の扱いを決める |

#### 未確定のため要判断

- 未参画メンバー（待機中）での表示有無 → 要件側も未確定として残っている
- 一覧画面に出すか、詳細画面だけにするか（列が増えて横幅を圧迫する）

### #2 Lavender組み込み方針への変更

- **起点コミット**: `0d47059` docs: change to Lavender integration approach with new SES sidebar section
- **要件の出典**: [Lavender組み込み要件](../requirements/lavender-integration.md)

#### 要件の内容

独立したWebシステムではなく、既存の管理画面Lavender（2way Manage system）の1機能として追加する。
サイドバーにFUKURO2.0とは別の大項目「SES」を新設し、その配下に「スキルシート」「案件一覧」を置く。

#### 現在のモックとのズレ

| 項目 | 現在のモック | 要件（Lavender準拠） |
|------|------------|-------------------|
| ヘッダー | 「SES管理システム」 | 「2way Manage system」 |
| サイドバーの大項目 | 「スキルシート」「案件（MVP・別担当）」「その他」 | 「FUKURO2.0」「SES」 |
| FUKURO2.0のメニュー | 表示なし | 既存13項目が上に並ぶ |
| サイドバー幅・配色 | 独自 | 幅240px / 背景 `#e0e0e8` |
| パンくず | あり | Lavenderに既存の仕組みがない |
| UI実装 | 独自CSS | Material-UI v4 |
| パス表記 | 画面遷移のみ（URL無し） | `/skill-sheet`、`/project` |
