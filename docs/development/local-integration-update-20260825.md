# ローカル統合環境 修正・検討記録（2026-08-25）

Lavender・Thymeを使用したローカル統合環境で確認した修正内容と、保留・検討事項を記録する。

## 1. 対応済み

### メンバー新規登録の日付入力

- 生年月日、稼働可能時期を連続入力した際、年が6桁になり `yyyyyy/mm/dd` と表示される問題を修正した。
- 年は4桁を上限とし、`yyyy/mm/dd` 形式で表示する。

### スキルシートの経歴順

- 先頭の経歴行が空欄で、2件目以降が入力済みの状態において、末尾行を編集すると先頭行と末尾行が入れ替わる問題を修正した。
- 他の経歴を編集しても、入力済みの表示順を自動変更しない。

### 1年未満の経験期間表示

- 12か月未満の経験期間を「0年」と表示せず、「6ヶ月」のように月単位で表示する。
- スキルシートのスキルサマリー、編集画面の補助表示、メンバー一覧のスキル表示を同じ形式にそろえる。
- 12か月以上は「1年」「1年3ヶ月」のように表示する。
- 経験期間が未登録の場合は `null年` とせず、期間を付けずにスキル名だけを表示する。

### 要員メール一覧の列幅

- 年齢は「99歳」、性別は「男性」「女性」「その他」が途中で折り返されない列幅とする。

### 一覧上部のページ操作

- 案件メール一覧と要員メール一覧は、表の上と下の両方にページ操作を表示する。
- 上下いずれでも、1ページの表示件数、表示範囲、前後ページを操作できる。
- 上下の操作状態は連動する。

## 2. 保留

### 稼働可能時期と入社日・提案日の扱い

メンバー新規登録の「稼働可能時期」に入力した日付が、メンバー一覧では社員の場合「入社日」、BPの場合「提案日」として表示されている。

- 稼働可能時期と入社日・提案日は意味が異なるため、同じ値を流用しない。
- 社員には入社日の入力欄と保存先、BPには提案日の入力欄と保存先が必要かを整理する。
- API・DB項目を含むデータの紐付け方針が決まるまで実装を保留する。

## 3. 要検討

### 案件メール一覧・要員メール一覧のスクロール

- 1ページの最低表示件数が50件のため、表の最下部にだけ横スクロールバーがあると操作しづらい。
- 表内へ縦スクロールを導入すると横スクロールバーへ到達しやすい一方、ページ全体と表内の縦スクロールが二重になる。
- 表の高さを制限せず、上側にも連動する横スクロールバーを置く案も含めて操作性を比較する。
- 現時点では縦横スクロールバーの追加は確定せず、従来の表の高さを維持する。
