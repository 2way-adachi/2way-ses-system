# 開発体制と役割分担

3人開発を前提に、担当範囲と開発工程を整理する。

- 作成日: 2026-08-03
- ステータス: ドラフト（初版）

---

## 1. 分割方針

技術レイヤー単位ではなく、**機能単位**で分ける。

| 担当 | 領域 |
|------|------|
| 担当A | 共通基盤、DB、API |
| 担当B | スキルシート管理 |
| 担当C | 案件メール取り込み |

---

## 2. 担当A：共通基盤、DB、API

### 責任範囲

- プロジェクト初期構築
- DB設計
- マイグレーション
- 共通API
- ファイル保存方式
- 共通エラーハンドリング
- ローカル開発環境
- 担当B、Cとのインターフェース調整
- 余力がある場合の仮マッチング

### 進め方

先にOpenAPIやサンプルJSONを作成し、担当B、CがAPI完成を待たずに作業できるようにする。

---

## 3. 担当B：スキルシート管理

### 責任範囲

- 既存Excelの構造解析
- Excelインポート
- スキルシート一覧
- スキルシート詳細
- スキルシート新規作成
- スキルシート編集
- 職歴管理
- スキル管理
- 資格管理
- 自己PR管理
- PDF表示または印刷用画面

---

## 4. 担当C：案件メール取り込み

### 責任範囲

- メールサービス接続
- 対象メール検索
- メール本文取得
- 案件情報抽出
- 案件DB登録
- 重複登録防止
- 取り込み履歴
- 案件一覧
- 案件詳細、編集

---

## 5. 開発工程

### 工程1：仕様固定

3人で以下を決める。

- スキルシート項目
- 案件項目
- 対象Excelフォーマット
- 対象メールサービス
- 対象メールの判定条件
- API一覧
- 画面一覧
- サンプルJSON

### 工程2：共通基盤

| 担当 | 作業 |
|------|------|
| A | DB、API、環境構築 |
| B | Excel解析検証、画面モック |
| C | メール取得検証、案件画面モック |

### 工程3：機能実装

| 担当 | 作業 |
|------|------|
| A | 共通API、DB、保存処理 |
| B | Excel取り込みからスキルシート管理まで |
| C | メール取得から案件登録まで |

### 工程4：結合

- スキルシート画面とAPIの結合
- 案件画面とAPIの結合
- Excel取り込み確認
- メール取り込み確認
- 重複登録防止確認
- 編集内容の保存確認

### 工程5：仮マッチング

**余力がある場合のみ実施する。**

案件必須スキルと人材スキルの単純一致数で候補者を並べる。

---

## 6. 未確定事項

- 担当A、B、Cの実担当者の割り当て
- 技術スタック（工程1で確定）
- ブランチ運用、レビュー体制
- 各工程の期間
